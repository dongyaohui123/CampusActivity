校园活动系统数据库 E-R 图（简明版）
依据 localhost_bishe 数据源中的 campus_activity_v2 数据库整理，保留主键、外键及核心业务字段
图例：
PK = 主键　FK = 外键
1:1 = 一对一　1:N = 一对多　M:N = 多对多
中间表用于表达收藏、报名、分类关联、关注等业务关系
用户与账户侧
活动核心链路
分类与审核侧

认证令牌

auth_tokens

  • PK id
  • FK user_id
  • 令牌类型、过期时间、是否撤销

用户

users

  • PK id
  • 用户名、微信openid、手机号
  • 角色 role、状态 status

学生资料

student_profiles

  • PK/FK user_id
  • 学号、真实姓名
  • 学院、专业

登录日志

login_logs

  • PK id
  • FK user_id
  • 登录结果、登录时间

组织者资料

organizer_profiles

  • PK/FK user_id
  • 组织名称、组织类型
  • 认证状态、联系电话

活动

activities

  • PK id；FK organizer_id、publisher_id
  • 活动标题、开始时间、结束时间
  • 人数上限、活动状态、可见性

报名记录

activity_registrations

  • PK id
  • FK activity_id、user_id
  • 报名状态、报名时间、签到时间

收藏

activity_favorites

  • PK id
  • FK activity_id、user_id
  • 创建时间

分类

activity_categories

  • PK id；FK parent_id
  • 分类名称、排序号
  • 状态 （支持父子分类）

活动分类关联

activity_category_rel

  • PK/FK activity_id
  • PK/FK category_id
  • 创建时间

当前审核

activity_reviews

  • PK/FK activity_id
  • FK reviewer_id
  • 审核状态、审核时间

审核日志

activity_audit_logs

  • PK id
  • FK activity_id、operator_id
  • 操作类型、创建时间

关注组织者

organizer_follows

  • PK id
  • FK organizer_id、user_id
  • 创建时间
说明：本图以 users 为中心实体，activities 为业务主表，展示用户、分类、报名、审核、收藏与关注等核心关系。
